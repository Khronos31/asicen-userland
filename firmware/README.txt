asicen-loader.bin is the Linux loader image for PX-S3U, PX-S3U2, PX-W3U2, and PX-W3U3.
Size: 16384 bytes.
SHA-256: b45d510200a1690b3ca358d93de13f40e1d3567b663c17e773349ad96f597aa8

It is checked out so GitHub-hosted runners can copy it into distribution archives.
Corresponding-source archives omit this directory (export-ignore, and the source
snapshot skips firmware/*). Redistribution rights remain unresolved. Inclusion
does not mean those rights are cleared, and this file is not covered by the
project GPL.

The PX-W3U3 V2 image (SHA-256 5db39facda140bdcb3a238dad10da5aac752a1ba3aaf17e2239f8d79a0ad6a2a)
is a different 16384-byte file and is not in this directory.
